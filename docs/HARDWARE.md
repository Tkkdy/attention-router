# 硬件与接线

## 已核对的范围

源码 `config.h` / `pages.cpp` 与本机 GxEPD2 1.6.9 的 `gdey3c/GxEPD2_420c_GDEY042Z98.h` 一致：GDEY042Z98、400×300、黑白红三色，驱动类 `GxEPD2_420c_GDEY042Z98`。厂商页面也列为 SSD1683、SPI：
https://www.good-display.com/blank7.html?productId=387 。

这是代码和既有硬件记录的交叉核对；本次未读取当前实物丝印、未拍照、未上电验收。历史记录标注 ESP32 DevKitC V4 / ESP32-WROOM-32E；当前实物身份、屏幕转接板型号及输入电压仍待所有者确认，不能把下面信息理解为所有屏幕套件的购买保证。

准备：经典 ESP32 开发板（4 MB Flash 目标）、对应 GDEY042Z98 屏及匹配的 SPI 转接/驱动板、USB 数据线、可靠电源及杜邦线。不要把裸 FPC 屏直接接 GPIO。

| 屏幕转接板信号 | ESP32 GPIO |
| --- | --- |
| BUSY | 4 |
| CS | 5 |
| RST | 16 |
| DC | 17 |
| SCK / CLK | 18 |
| MOSI / DIN | 23 |
| GND | 共地 |
| VCC | 按已确认的转接板规格接入，见下文 |

GxEPD2 明确要求裸屏的供电和数据线为 3.3 V；ESP32 GPIO 也应使用 3.3 V 逻辑。转接板是否具有稳压/电平转换、是否允许 5 V 输入不能从驱动代码确定。**转接板型号和输入电压确认前不要接 VCC；不要把 5 V 接到裸屏或 GPIO。** ESP32 开发板 USB 供电不等于屏幕 VCC 也接 5 V。电源电流余量按板卡资料确认，本包不编造额定电流。

串口 115200。`H/W/I/R/?` 是开发显示命令；不是实体按键 ACK。提醒页明确指向 Web ACK，本版本没有经过验收的物理 ACK 按钮路径。

## 候选真机验收边界

私人运行版本有断连降级、稳定窗口恢复和联网后任务标题恢复的观察记录；这些记录不是本公开候选精确固件的验收。当前原板运行固件身份仍为 UNKNOWN，离线冷启动曾刷新出 STALE 页面及 ASCII 任务占位标题。最终候选尚未完成精确构建身份、NVS 与实屏闭环。

原板 NVS 诊断已经冻结，刷写为 **No-Go**。仅回滚应用无法恢复被合成数据改变的 NVS；现有 supervisor 定时恢复机制也不能保证测试/回滚期间不干扰。以下是未来在**兼容备用板、隔离数据和独立测试网络**上的有限基础验收清单，不授权操作现用原板，不要求为了私人历史问题继续开发诊断功能。

## 备用板基础验收（另行批准，本候选未执行）

1. 记录 ESP32 与屏幕/转接板丝印或照片，核实 VCC、GND、逻辑电压和上表引脚。
2. 记录最终源码版本、工具链、构建产物哈希；在独立目录只填测试网络与隔离 Hub 地址。确认目标分区、安全状态、容量及写入范围；有原数据时先验证备份与完整回滚条件。由所有者确认目标备用板并批准刷写，保留刷写/启动证据对应同一构建身份。
3. 仅启动隔离 Hub，使用可信测试局域网、新数据库和合成任务。既有示例为英文；若验收中文，须使用明确标为测试的中文显示名及可用字体，观察 Home 黑/白/红、400×300 布局与中文字形，不以串口日志代替屏幕确认。
4. 运行示例，查看 Todo 和当前任务；手动 CODING 观察 Workspace，等待提醒进入 Interrupt。
5. 在浏览器点击 ACK，确认提醒消失、原页面恢复、Todo 没被误标完成；记录可能的 30 秒拉取与屏幕刷新延迟。
6. 仅停止新 Hub 或断开测试网络，确认约 90 秒后断连/STALE 行为；恢复新 Hub 后检查 45 秒稳定恢复窗口，不触碰原运行服务。
7. 在备用板上记录缓存写入错误、离线冷启动后的实际标题/STALE 与联网后更新；断电仅由所有者批准并操作。Todo 元数据、Last Scene 中文位图、Standalone Home 分开记录；未配置独立来源时 Home 缓存缺失不自动等于写入失败。主机 fake NVS 不能替代实物证据。

该清单用于明确基础功能的已测/未测范围，不要求穷尽高级集成或修复私人旧 NVS。私人离线中文标题原因可作为后续 Issue；如果最终候选默认路径也复现同一现象，应记录为候选缺陷并决定最小修复或明确限制，不能宣称“离线中文无损恢复已通过”。源码 Preview 的发布准备可以继续，源码公开已获所有者批准，设备操作仍须另行批准。
